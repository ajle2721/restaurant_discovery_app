# Environment-Specific Agent Instructions

Before working in this repository, determine the operating environment and read exactly one of the following instruction files:

- On Windows, read and follow `AGENTS-WIN.md`.
- On NixOS or a Linux environment that uses the repository's Nix development shell, read and follow `AGENTS-NIX.md`.

Do not combine platform-specific commands from both files. If the environment is unclear, inspect the operating system and available tooling before proceeding. The selected file contains the complete repository guidelines for that environment.
